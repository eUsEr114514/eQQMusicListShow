# 开发说明 · 114514123 歌单漫游

面向要改这个页面的人。全部是原生 HTML/CSS/JS，没有构建、没有依赖、没有网络请求。

---

## 1. 文件职责

```
index.html          结构（脚本已抽到 styles/interaction.js）
styles/base.css     主题变量、极光背景、页头、工具栏、提示
styles/cards.css    卡片网格、封面、徽标、频谱动画
styles/player.css   底部播放器、响应式断点
styles/interaction.js  全部交互逻辑（playAt / 筛选 / 快捷键）
data/tracks.js      window.PLAYLIST = { meta, tracks[] }，每首带 src 直链
SongsFiles/         本地音频缓存：{编号}-{歌名}.mp3|.flac|.m4a（.gitignore，不进仓库）
SongsCover/         封面：{编号}-{歌名}.jpg（入库）
_tools/             upload_release.py（上传音频到 Release）、gen_src.py（把直链写回 tracks.js）
```

音频**不入库**，全部托管在 GitHub Release `songs-v1`；`data/tracks.js` 里每首的 `src` 就是 Release 直链，例如：

```
https://github.com/eUsEr114514/eQQMusicListShow/releases/download/songs-v1/3-Yu_Lu_Shuang_Xue.flac
```

页面优先播放 `src`；直链失败（离线、被墙、资源被删）时自动回落到本地 `SongsFiles/` 同名文件，所以本地有文件时依旧能离线听。

`index.html` 加载顺序：三个 `<link>` → `<script src="data/tracks.js">` → `<script src="styles/interaction.js">`。

## 2. 数据结构

```js
window.PLAYLIST = {
  meta: {
    title: "114514123",                  // 页面大标题
    subtitle: "QQ音乐歌单 · 本地音频漫游",   // 副标题
    source: "https://c6.y.qq.com/...",   // 仅存档，不参与渲染
    count: 778,                          // 头部「共 N 首」，用数组长度算也行
    seconds: 161000,                     // 总秒数（头部 44h10m）
    kb: 6550000                          // 总体积 KB（头部 6.3G）
  },
  tracks: [ /* 见下 */ ]
};
```

单曲对象字段：

| 字段 | 类型 | 说明 |
| --- | --- | --- |
| `n` | number | 唯一编号，用于高亮定位与「上次播放」记忆；**不参与排序**，重名会串台 |
| `title` | string | 歌名，卡片与播放器显示 |
| `artist` | string | 歌手，多人用 ` / ` 分隔 |
| `album` | string | 专辑，仅用于搜索与提示 |
| `cat` | string | 分类，必须是筛选条上的七个之一 |
| `file` | string | 不含扩展名的文件名，例如 `"3-雨露霜雪"`，对应 `SongsFiles/3-雨露霜雪.flac` |
| `ext` | string | `.mp3` / `.flac` / `.m4a` |
| `dur` | number | 秒，卡片显示 `m:ss` |
| `kb` | number | 文件大小（KB），卡片显示 `M` |
| `q` | string | `FLAC` / `320k` / `128k`，只影响徽标颜色 |
| `cover` | boolean | `false` 时不加载封面，显示 ♪ 占位 |
| `src` | string | 音频直链（GitHub Release）。存在时优先播放；缺省则用本地 `SongsFiles/` |

页面所有路径都会经过 `encodeURIComponent`（函数 `enc()`），所以文件名里有空格、括号、日文、中文都不用手动转义，**但不要包含 `/`、`?`、`#`**。

## 3. 新增曲目（重点）

默认顺序 = `tracks` 数组顺序。把条目放在数组**最前面**，它就是 1 号，原来的 1 号顺位变 2 号——页面不显示编号，但「歌单顺序」下就是这样排的。

### 第 1 步：准备文件

音频放进 `SongsFiles/`（不入库，只作本地缓存），命名 `{编号}-{歌名}.扩展名`，例如 `790-新曲名.mp3`。编号只要不与现有 `n` 重复即可，建议用当前最大值 +1。单文件 **≤ 25 MB**。

封面放进 `SongsCover/`，**文件名与音频完全一致**，扩展名 `.jpg`：`790-新曲名.jpg`。没有封面就把 `cover` 写成 `false`。

### 第 2 步：把音频传到 Release

Release 只接受 ASCII 资源名，中文/日文会被 GitHub 直接删掉，所以资源名固定为 `{编号}-{英文转写}.{扩展名}`，转写由 `_tools/upload_release.py` 里的 `slugify()`（unidecode）自动生成，例如：

```
3-雨露霜雪.flac  ->  3-Yu_Lu_Shuang_Xue.flac
790-新曲名.mp3    ->  790-Xin_Qu_Ming.mp3
```

单独补一首：

```bash
python _tools/upload_release.py --repo eUsEr114514/eQQMusicListShow --tag songs-v1 --token "$(gh auth token)" --limit 1
```

脚本会跳过已存在的资源，只补缺的；上传完自动更新 `_work/release_assets.json`。

### 第 3 步：把直链写回数据

```bash
python _tools/gen_src.py
```

它会读取 `_work/release_assets.json`，按编号把 `"src"` 写进 `data/tracks.js` 每一首，没有直链的会自动去掉该字段（回落到本地文件）。

### 第 4 步：在数组最前面插入条目

打开 `data/tracks.js`，在 `"tracks": [` 后插入：

```js
{
  "n": 790,
  "title": "新曲名",
  "artist": "歌手A / 歌手B",
  "album": "所属专辑",
  "cat": "vocaloid",
  "file": "790-新曲名",
  "ext": ".mp3",
  "dur": 213,
  "kb": 8200,
  "q": "320k",
  "cover": true,
  "src": "https://github.com/eUsEr114514/eQQMusicListShow/releases/download/songs-v1/790-Xin_Qu_Ming.mp3"
},
```

保存 → 刷新页面 → 它出现在第一位，原 1 号顺位后移。

### 第 3 步：同步头部统计（可选）

`meta.count / seconds / kb` 是写死的数字。不改也能用，但头部会显示旧数据。两项选择：

- 手动改：`count` 加 1，`seconds` 加 `dur`，`kb` 加 `kb`；
- 或忽略，控制台执行下面代码后把输出贴回文件：

```js
const t = PLAYLIST.tracks;
console.log(t.length, t.reduce((s,x)=>s+x.dur,0), t.reduce((s,x)=>s+x.kb,0));
```

### 关于 `n` 的取舍

`n` 只做唯一键。如果你更想让编号体现顺序，也可以把新曲命名为 `0-新曲名.mp3` 并把 `n` 设为 `0`，但**不要批量重命名已有文件**，否则 `下载清单.csv`、封面名、`tracks.js` 三处都要跟着改。

### 批量导入（可选）

`_work/gen_site3.py` 会扫描 `SongsFiles/` + `SongsCover/` + `_work/manifest.json` 重新生成 `data/tracks.js` 与 `下载清单.csv`。它适合**一次性重建**，会覆盖手工改动，所以：

- 手工维护 → 别跑这个脚本；
- 大批量导入 → 先在 `_work/manifest.json` 里补条目（字段：`n/name/artist_str/album/file/mid`），再跑脚本，分类从 `_work/cats.json` 取。

## 6. 分类：改名 / 增加

### 只改显示名（数据不动）

改 `.chip` 的文字即可，但 `data-cat` 必须保持与数据里的 `cat` 一致，否则筛不出东西：

```html
<div class="chip" data-cat="vocaloid">术力口<em data-count="vocaloid"></em></div>
```

### 改名（数据一起改）

1. `index.html` 里改 `.chip` 的文本与 `data-cat`；
2. `data/tracks.js` 里把该分类的所有 `"cat"` 批量替换成新名；
3. `下载清单.csv` 的分类列同步（可选）。

### 新增一个分类

```html
<div class="chip" data-cat="爵士">爵士<em data-count="爵士"></em></div>
```

计数会自动统计（脚本遍历 `tracks` 生成 `counts`）。然后给相关曲目的 `cat` 填 `"爵士"` 即可。

分类名不要含 `"`，不要用换行。

## 7. 改配色与极光背景

全在 `styles/base.css`。

### 换主色

```css
:root{
  --acc:#31c27c;    /* 主色：商标、选中态、播放按钮、进度条 */
  --acc2:#5b8cff;   /* 辅色：第二团光斑 */
  --hot:#ff5c8a;    /* 点缀：第三团光斑 */
  --bg:#07070b;     /* 页面底色 */
}
```

只改这几个变量，按钮、光斑、选中边框、进度条会一起变。

### 光斑数量 / 颜色 / 大小

HTML 里固定三团：`<div class="aurora"><i></i><i></i><i></i></div>`。加第四团就再加一个 `<i>`，并在 CSS 写 `nth-child(4)`：

```css
.aurora i:nth-child(4){
  width:28vw;height:28vw;left:10vw;top:50vh;
  background:radial-gradient(circle,#ffd166,transparent 62%);
  animation-delay:-3s;
}
```

调强度：`.aurora{filter:blur(70px);opacity:.55}`；调速度：`animation:float 18s`（改秒数，越大越慢）。

想做成静态渐变（不要动效），删掉 `.aurora i{animation:...}` 一行即可。

### 噪点

`.grain{opacity:.035}`，改成 0 就完全干净。

### 卡片与播放器

- 圆角：`--radius:16px`（`base.css`）
- 卡片悬浮位移与阴影：`cards.css` 的 `.card:hover`
- 播放器毛玻璃：`player.css` 的 `.player{ background:linear-gradient(...); backdrop-filter:blur(24px) }`

## 9. 快捷键：用法与修改

### 现有键位

| 键 | 行为 | 代码位置 |
| --- | --- | --- |
| `空格` | 播放/暂停 | `if (e.code === 'Space')` |
| `→` / `←` | 下一首 / 上一首 | `ArrowRight` / `ArrowLeft` |
| `↑` / `↓` | 音量 ±5% | `setVol(audio.volume ± 0.05)` |
| `/` | 聚焦搜索 | `$('#q').focus()` |
| `Esc` | 搜索框内退出焦点 | `e.target.blur()` |

### 增加新键位

在 `index.html` 末尾的 `document.addEventListener('keydown', ...)` 里加分支。例：`M` 静音、`R` 随机：

```js
else if (e.key === 'm' || e.key === 'M'){ e.preventDefault(); $('#mute').click(); }
else if (e.key === 'r' || e.key === 'R'){ e.preventDefault(); $('#shuffle').click(); }
```

数字键切分类（1–8 对应筛选条顺序）：

```js
const chipList = document.querySelectorAll('.chip');
if (/^[1-8]$/.test(e.key)) chipList[+e.key - 1].click();
```

### 注意事项

- 输入框/下拉框聚焦时脚本会提前 `return`，所以打字不会触发快捷键；想让某键在输入时也生效，把逻辑放到那个 `return` 之前。
- 用了 `e.preventDefault()` 的键会覆盖浏览器默认行为（例如空格滚动页面、`/` 打开查找）。
- 组合键判断用 `e.ctrlKey / e.metaKey / e.altKey`，例：

```js
if (e.ctrlKey && e.key === 'k'){ e.preventDefault(); $('#q').focus(); }
```

## 10. 播放逻辑怎么运转

```text
apply()     根据「分类 + 搜索 + 排序」算出 filtered
            → 重置网格 → renderMore() 分批渲染（每批 140，滚动到底自动续）
            → queue = filtered（播放队列就是当前筛选结果）

card 点击   在 queue 里找到该曲下标 → playAt(idx)

playAt(i)   audio.src = SongsFiles/文件 + ext
            → 更新播放器文案/封面 → 给对应卡片加 .on → 记住 qm_last
            播完按 mode：0 顺序下一首 / 1 单曲循环 / 2 随机
```

想改行为：

- **默认不自动播放**：`playAt` 里去掉 `audio.play()`；
- **双击才播**：把卡片监听改成 `dblclick`；
- **点击播放整张歌单**：在 `apply()` 后调用 `queue = tracks.slice()`；
- **默认音量**：`audio.volume = 0.85` 与 `let lastVol = 0.85` 两处一起改；
- **每批渲染数量**：`const PAGE = 140`；
- **懒加载预取距离**：`IntersectionObserver` 的 `rootMargin:'600px'`。

## 11. 调试与排错

| 现象 | 排查 |
| --- | --- |
| 卡片全是 ♪ 占位 | `SongsCover` 文件名与 `file` 不一致，或 `cover:false` |
| 点了没声音、控制台报 `该文件无法播放` | `ext` 与实际扩展名不符；或文件本身损坏 |
| 某个分类点进去是空的 | 该分类的 `data-cat` 与数据 `cat` 不一致（大小写、斜杠、空格） |
| 计数显示 0 | `data-count` 的值与 `cat` 不一致 |
| 改了标题没反应 | JS 用 `meta.title` 覆盖了 `#siteTitle` |
| 中文/日文文件名 404 | 文件名里出现了 `/` 或以 `.` 结尾；Windows 上不允许 |

查看实际请求：F12 → Network，筛 `SongsFiles`；查看数据结构：控制台执行 `PLAYLIST.tracks[0]`。

## 12. 部署差异

- **file://**：直接双击可用，`localStorage` 正常；个别浏览器对本地媒体自动播放更严格。
- **http://**：推荐，行为最接近线上；手机访问用 `python -m http.server`，注意同一网段与防火墙。
- 不要用 `file://` 版本从别的目录引用（复制时保持 `styles/`、`data/`、`SongsFiles/`、`SongsCover/` 与 `index.html` 同级）。
